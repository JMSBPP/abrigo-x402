**Q96 formula (RESEARCH §A — HIGH-confidence; UniswapV3Pool.sol L718-719 verbatim):**

Source: `state.feeGrowthGlobalX128 += FullMath.mulDiv(step.feeAmount, FixedPoint128.Q128, state.liquidity)`

Direct decomposition (bypasses feeGrowthGlobal accumulator):
```
gross_input  = abs(swap_input_amount) × 1e6 / (1e6 - fee_tier_bps)
step.feeAmount = gross_input × fee_tier_bps / 1e6
             = abs(swap_input_amount) × fee_tier_bps / (1e6 - fee_tier_bps)

vault_fee_in_token = step.feeAmount × (vault_in_range_liquidity / swap.liquidity)

where:
  vault_in_range_liquidity = vault_liquidity if vault.lowerTick ≤ swap.tick ≤ vault.upperTick else 0
  swap.liquidity = Swap event's `liquidity` field (pool-side liquidity at swap time)
  swap_input_amount = whichever of {amount0, amount1} is POSITIVE in the decoded Swap
                      (zeroForOne → amount0 > 0; else amount1 > 0)
```

**Input DataFrame schema (after decoders.decode_all + vault_state.attach_in_range):**
```
event_name: String
amount0: String (decimal-string from int256; can be negative — sign indicates direction)
amount1: String
liquidity: String (decimal-string from uint128; swap.liquidity, pool-side)
tick: Int32
vault_in_range: Boolean
vault_liquidity: String  (proxy: totalSupply OR a vault-specific liquidity field — see Plan 02-04 attach_in_range output)
totalAmounts_0: String   (used to derive vault_liquidity proxy if needed)
totalAmounts_1: String
totalSupply: String
lowerTick: Int32
upperTick: Int32
```

**For ICHI cKES/USDT anchor pool:** `fee_tier_bps = 100` (0.01%) per `protocols/ichi.toml`.

**Vault liquidity proxy decision:** ICHI vaults expose `totalSupply()` (LP-share token total) but the vault's actual Uniswap V3 position liquidity is queried via `pool.positions(keccak256(vault, lowerTick, upperTick))`. For Phase 2 simplicity, use `totalSupply` as the proportionality proxy (the vault's `totalAmounts` are derived from its actual L liquidity scaled by its tick range; the ratio `vault_L / pool_L` is approximately `totalSupply / pool.liquidity` up to ICHI's auto-rebalance dynamics — within the 1% precision target per Pitfall 2 warning sign). Document this approximation in the module docstring. A precise computation (via `pool.positions(...)`) is deferred to Phase 7 if a captured `collectFees` cross-check shows >1% drift.

**Polars Decimal arithmetic:** RESEARCH Pitfall 6 — explicit casts required. Use Python `int` arithmetic via `pl.Expr.map_batches` OR cast to Decimal[38, 0] and do arithmetic with explicit precision. For Phase 2 we use the polars `String → Int128` ingestion pattern via `pl.col(...).cast(pl.Decimal(38, 0))` then arithmetic.

```python
    return pl.DataFrame({

        "amount0": [str(amount0)],

        "liquidity": [str(liquidity)],
        "tick": [12345],

    df = _make_swap(amount0=1_000_000_000_000_000_000, amount1=-998_000, liquidity=5_000_000_000_000_000_000)
```

```python
"""Q96 LP-fee math from raw Uniswap V3 Swap events.

Per UniswapV3Pool.sol L718-719 (verified live via WebFetch 2026-05-26):
    state.feeGrowthGlobalX128 += FullMath.mulDiv(step.feeAmount, FixedPoint128.Q128, state.liquidity)

Direct decomposition (RESEARCH §A — HIGH confidence):
    step.feeAmount   = abs(swap_input) × fee_tier_bps / (1e6 - fee_tier_bps)
    vault_fee_token  = step.feeAmount × (vault_in_range_liquidity / swap.liquidity)

The Swap event emits NET amounts (amount0, amount1); the input side has the POSITIVE
sign (zeroForOne ⇒ amount0 > 0; else amount1 > 0). Recover gross-input via
fee_tier_bps / (1e6 - fee_tier_bps) factor — see Pitfall 2 in RESEARCH.

Vault liquidity proxy (Phase 2 simplification): use vault_liquidity column populated
upstream by vault_state.attach_in_range (sentinel: vault's totalSupply). A precise
pool.positions(vault, lower, upper).liquidity computation is deferred to Phase 7 if
a captured collectFees cross-check shows >1% drift (Pitfall 2 warning sign).
"""
import polars as pl

Q128: int = 2**128

def _abs_str_int(col: str) -> pl.Expr:
    """polars expression: abs(int-cast-from-decimal-string)."""
    return pl.col(col).cast(pl.Decimal(precision=38, scale=0)).abs()

def compute_swap_fee(df: pl.DataFrame, fee_tier_bps: int) -> pl.DataFrame:
    """Add fee_token0, fee_token1, vault_fee_token0, vault_fee_token1 columns.

    All four columns are emitted as decimal-strings (polars String dtype) so that
    sum/aggregation in Plan 02-08 + Plan 03 can choose Int / Decimal arithmetic
    explicitly without silent Float64 coercion (Pitfall 6).
    """
    fee_factor_num = fee_tier_bps
    fee_factor_den = 1_000_000 - fee_tier_bps

    # Cast text → Decimal[38, 0] for safe BigInt arithmetic
    work = df.with_columns(
        pl.col("amount0").cast(pl.Decimal(precision=38, scale=0)).alias("_amt0_dec"),
        pl.col("amount1").cast(pl.Decimal(precision=38, scale=0)).alias("_amt1_dec"),
        pl.col("liquidity").cast(pl.Decimal(precision=38, scale=0)).alias("_swap_L_dec"),
        pl.col("vault_liquidity").cast(pl.Decimal(precision=38, scale=0)).alias("_vault_L_dec"),
    )

    # fee_token0: when amount0 > 0 (zeroForOne), abs(amount0) * fee_tier / (1e6 - fee_tier); else 0
    # fee_token1: when amount1 > 0 (oneForZero), abs(amount1) * fee_tier / (1e6 - fee_tier); else 0
    work = work.with_columns(
        pl.when(pl.col("_amt0_dec") > 0)
          .then((pl.col("_amt0_dec") * fee_factor_num) // fee_factor_den)
          .otherwise(pl.lit(0).cast(pl.Decimal(precision=38, scale=0)))
          .alias("_fee_token0_dec"),
        pl.when(pl.col("_amt1_dec") > 0)
          .then((pl.col("_amt1_dec") * fee_factor_num) // fee_factor_den)
          .otherwise(pl.lit(0).cast(pl.Decimal(precision=38, scale=0)))
          .alias("_fee_token1_dec"),
    )

    # vault_fee_token0 = fee_token0 * vault_L / swap.L when vault_in_range; else 0
    # vault_fee_token1 = fee_token1 * vault_L / swap.L when vault_in_range; else 0
    work = work.with_columns(
        pl.when(pl.col("vault_in_range") & (pl.col("_swap_L_dec") > 0))
          .then((pl.col("_fee_token0_dec") * pl.col("_vault_L_dec")) // pl.col("_swap_L_dec"))
          .otherwise(pl.lit(0).cast(pl.Decimal(precision=38, scale=0)))
          .alias("_vault_fee_token0_dec"),
        pl.when(pl.col("vault_in_range") & (pl.col("_swap_L_dec") > 0))
          .then((pl.col("_fee_token1_dec") * pl.col("_vault_L_dec")) // pl.col("_swap_L_dec"))
          .otherwise(pl.lit(0).cast(pl.Decimal(precision=38, scale=0)))
          .alias("_vault_fee_token1_dec"),
    )

    # Emit as decimal-strings for downstream stability (Pitfall 6)
    out = work.with_columns(
        pl.col("_fee_token0_dec").cast(pl.String).alias("fee_token0"),
        pl.col("_fee_token1_dec").cast(pl.String).alias("fee_token1"),
        pl.col("_vault_fee_token0_dec").cast(pl.String).alias("vault_fee_token0"),
        pl.col("_vault_fee_token1_dec").cast(pl.String).alias("vault_fee_token1"),
    ).drop(["_amt0_dec", "_amt1_dec", "_swap_L_dec", "_vault_L_dec",
            "_fee_token0_dec", "_fee_token1_dec",
            "_vault_fee_token0_dec", "_vault_fee_token1_dec"])
    return out
```
