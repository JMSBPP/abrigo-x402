# Phase 04.1.1 Plan 02: lr_test.py Option A + profile_likelihood.py Constrained-MLE CI Summary

One-liner: Re-established the LR and branching-CI gate criteria on the corrected scipy_canonical_ll estimator — lr_test.py now runs Option A (one scipy observed fit + 1000 cheap tick-LS null replicates) with the 6.05M observed-LL-scale pathology resolved, and profile_likelihood.py computes a genuine constrained-MLE η-CI (re-optimize the canonical LL s.t. ρ(α/β)=η at each grid point) replacing the retracted projection trick.

## What was built

### Task 1 — lr_test.py Option A (scipy observed + tick-LS null) + observed-LL-scale fix

- Added module-private `_fit_hawkes_ls_for_null(sim_0, sim_1, decays)`: rescales to t=0 origin (Hawkes LL is shift-invariant) and calls `hawkes_fit._fit_with_gofit(..., gofit="least-squares")`, returning the `{baseline, adjacency, decays, branching_ratio, fit_method_used}` dict the bootstrap loop consumes, tagged `fit_method_used == "least-squares-null-replicate"`.
- The bootstrap loop's null-replicate fit switched from `fit_hawkes_expkern` (scipy, ~4.3s) to `_fit_hawkes_ls_for_null` (tick-LS, ~0.024s/rep). The downstream canonical LL via `_hawkes_loglik_vectorized` is unchanged, so the null LR_b is on the same scale as the scipy-observed LR.
- The OBSERVED fit stays `fit_hawkes_expkern` (scipy_canonical_ll free-β AIC). Because `ll_hawkes_obs` is computed from the scipy-fitted params under the canonical LL, the prior 6.05M observed_stat (LS-fallback-params-into-canonical-LL artifact) is resolved — the observed_stat is now finite and physically scaled. Documented inline + in the bootstrap-performance docstring block.
- n_reps=1000 production lock (AF-04) UNCHANGED; Option A only makes each replicate cheap. SC-3 grep gate intact.

### Task 2 — profile_likelihood.py genuine constrained-MLE η-CI

- Added `_constrained_profile_loglik(eta_value, leg_0, leg_1, decays)`: at the fixed `eta_value`, re-optimizes the canonical `_hawkes_loglik_vectorized` over (λ₀[2], α[2,2]) with the constraint ρ(α/β)==eta_value enforced EXACTLY inside the objective — the raw α is renormalized (`anorm = araw * (eta_value / rho_raw)`) so its spectral radius equals `eta_value·β` before the LL is evaluated. Multi-start L-BFGS-B with positivity bounds.
- `LL_max` is now the UNCONSTRAINED joint-MLE LL, recomputed via `_hawkes_loglik_vectorized` at the scipy canonical params — NOT the max over a projected family. `eta_hat = hawkes_fit["branching_ratio"]` (the joint-MLE η), NOT the grid argmax.
- `method` literal changed to `"constrained_mle_profile"`; the `from abrigo_x402.dgp.hawkes_fit import fit_hawkes_with_fixed_branching_ratio` import (projection trick) removed; `"projection"` literal gone; `eta_hat_unconstrained` key dropped (now equals eta_hat). Keys `eta_hat, lower, upper, ci_width, alpha, q9_nullfire_triggered, q9_threshold` preserved → `branching_ci_excludes_zero = lower > 0` still resolvable.
- `fit_hawkes_with_fixed_branching_ratio` LEFT INTACT in hawkes_fit.py (consume-only invariant; still re-exported in `dgp/__init__.py`; no orphaned importers).
